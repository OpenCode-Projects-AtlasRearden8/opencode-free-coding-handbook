# Free AI Coding with OpenCode

A beginner-friendly, plain-English manual for coding with AI at zero cost, built around
[OpenCode](https://opencode.ai) — the open-source AI coding agent that runs in your terminal.

Eleven chapters cover installing OpenCode, picking free models (cloud free tiers, subscriptions
you may already own, and fully local models), permissions and safety, writing good task prompts,
Git basics, reviewing AI changes honestly, the real limits of free tiers, and systematic
troubleshooting — plus a pocket appendix of checklists. Tables and checklists throughout,
no jargon left unexplained, and a hard rule from page one: *never let the AI be the only
person who understands your project.*

## Build the site yourself (optional)

The built site lives in `site/`. To rebuild it after editing the chapters:

```bash
pip install -r requirements.txt   # installs the `markdown` package
python3 build.py                  # regenerates site/
```

OpenCode's own documentation at <https://opencode.ai/docs> is the always-current
companion to this book; commands and config here follow its documented shape.

## Run the tests

```bash
python3 -m unittest discover -s tests -v
```

The test suite verifies book structure and length, markdown-to-HTML conversion
(headings, tables, fenced code, checkbox styling, link rewriting), the generated
site (files, navigation, no external assets), a privacy sweep for secret-shaped
strings, and the LICENSE line.

## Repository layout

```
docs/     The manual — Markdown chapters (source of truth)
site/     The built static website (generated by build.py)
tests/    Test suite (unittest, standard library)
build.py  Site builder: docs/*.md -> site/*.html
```

## Privacy-first by design

The build uses no network access, the site loads no external assets, and the test
suite fails if secret-shaped strings appear in the book.
Repository convention: no API keys, no personal data.
